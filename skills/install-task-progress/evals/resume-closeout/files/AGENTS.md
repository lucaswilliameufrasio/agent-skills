# Fixture policy

Use .agent-tasks/<task-id>.md for the live plan; read the exact matching task
before resuming. Durable outcomes belong in docs/task-outcomes/<task-id>.md.
Preserve blocked and unrelated tasks, evidence, and docs/decisions.md history.
Read durable closeout back before deleting the completed task's exact file.
No network, Git writes, package installs, or application execution.
