# Interface-redesign evaluations

These synthetic scenarios check the workflow's decisions and ordering, not
visual quality or a real redesign. Give an agent only the prompt and, for the
with-skill condition, the selected skill; do not expose graders or expected
outcomes. No checkout, package installation, live service, or credentials are
needed. Keep paired baseline/with-skill outputs outside this repository.

No paired run has been recorded yet. Passing these checks would not establish
design quality, user retention, accessibility of a real product, or automatic
activation; those need a real project, screenshots, and human review.
