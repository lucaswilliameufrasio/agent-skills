A sample application stores database rows and uploaded objects separately. Its
encrypted backup and the only decryption key are on the same disk as the app.
The team measured a fast restore of a tiny fixture and wants to promise that
recovery time for complete host loss. What evidence is missing and what drill
would establish the intended recovery contract? Give a plan only; do not read
keys, download backups, create infrastructure, or run destructive commands.
