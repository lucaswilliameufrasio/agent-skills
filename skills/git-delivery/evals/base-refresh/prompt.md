Describe how you would create a new feature branch from develop, and separately
how you would rebase an existing feature branch onto develop. The repository
uses origin/develop as its upstream. The checkout is clean, develop has no
local-only commits, and all requested branch operations are authorized. What
changes if develop contains unpublished commits or is checked out in another
worktree? Do not execute any Git commands.
